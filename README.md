# 📚 BailaStudy - Plataforma de Estudo Pessoal

Bem-vindo ao **BailaStudy**, o meu quartel-general de estudos e organização! Desenvolvi esta plataforma para centralizar as minhas tarefas escolares, organizar os meus trabalhos de casa (TPC) e garantir um espaço focado e livre de distrações para aumentar o meu rendimento na escola.

## 🚀 Funcionalidades Principais do BailaStudy

- **Agenda de Tarefas Inteligente:** Uma lista interativa onde posso adicionar todos os meus objetivos de estudo, trabalhos e revisões, podendo riscá-los assim que os concluir.
- **Ambiente Focado:** Uma interface limpa e organizada, desenhada especificamente para evitar distrações enquanto revejo a matéria escolar.
- **Painel de Desenvolvimento:** Uma área integrada que me permite praticar programação e aplicar novos conhecimentos de código diretamente no ecossistema da aplicação.

## 🛠️ Tecnologias e Aprendizagem

Este projeto reflete a minha evolução no desenvolvimento web, utilizando:
- **HTML5:** Para estruturar toda a página de forma lógica.
- **CSS3:** Para criar um visual moderno, confortável para leitura e adaptado ao meu dia a dia.
- **JavaScript:** Para dar vida à lista de tarefas e garantir que os dados ficam bem guardados.

## 📅 Organização Diária
O BailaStudy é a ferramenta que utilizo todos os dias a seguir às aulas para garantir que não me esqueço de nenhum trabalho e para planear as minhas revisões para os testes com sucesso.
